Short: Per-task agent session stats

A new Agent sessions screen lists every live Claude task session with summary tiles (live sessions, warm caches, sessions that need you, spend) and a table of context use, prompt cache state and expiry, cost, model and the account each session bills, sortable by column, searchable by title or task number, and filterable by project and account. Each row opens its task or expands to show tokens, cache reads and writes, hit ratio, duration, lines changed, effort and thinking. The header usage panel pins a Sessions footer with the session count, warm caches, total cost, at most three sessions that need you now (a cache about to expire while the task waits on you, or context at 85% or more) and an All sessions button; the screen is also in View → Show Agent Sessions, the header More menu and the command palette.
