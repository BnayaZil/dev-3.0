Short: File explorer beside every terminal

A read-only file explorer now sits beside the task terminal, listing the task's worktree, and on the project terminal screen, renamed Repo, listing the project folder: click a file to preview it, or right-click to copy its path or insert it into the terminal. Pin it as a resizable column or let it auto-hide, and toggle it with the Explorer button, ⇧⌘E (Ctrl+Shift+B on Linux and Windows), the View menu or the palette; on a board the shortcut opens Repo with the tree shown.
